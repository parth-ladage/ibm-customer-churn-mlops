1. Problem Statement

Develop and operationalize an end-to-end Machine Learning Web Application for IBM Customer Churn Prediction by implementing the complete MLOps lifecycle. Use Git for local source code version control, GitHub for remote repository hosting and collaborative workflows, Docker for portable application containerization, Jenkins (running in an isolated Docker container) for automated Continuous Integration and Continuous Deployment (CI/CD) pipelines, and Evidently AI / MLflow for continuous data quality and data drift monitoring on the customer churn dataset. Configure each tool, verify its installed version, establish pipeline automation via a declarative Jenkinsfile, and execute commands to demonstrate the seamless progression of code from commit through automated testing, container build, deployment, and real-time monitoring.

1. Environment Setup:

Declarative Jenkins Pipeline (Jenkinsfile):
pipeline {
    agent any
    environment {
        IMAGE_NAME = "churn-api"
        IMAGE_TAG = "latest"
        PORT = "8000"
    }
    stages {
        stage('1. Checkout') { steps { checkout scm } }
        stage('2. Dependencies') { steps { sh 'pip install -r requirements.txt' } }
        stage('3. Unit Testing') { steps { sh 'pytest tests/test_api.py' } }
        stage('4. Docker Build') { steps { sh 'docker build -t ${IMAGE_NAME}:${IMAGE_TAG} .' } }
        stage('5. Deploy') { steps { sh 'docker run -d -p 8000:8000 ${IMAGE_NAME}:${IMAGE_TAG}' } }
        stage('6. ML Monitoring') { steps { sh 'python3 src/monitor_churn.py' } }
    }
}

6. Additional Monitoring Tool: Evidently AI — Data Quality & Drift Monitoring (IBM Customer Churn)

1. Environment Setup:
Integrate Evidently AI data observability engine for continuous production monitoring of the IBM Customer Churn pipeline. Establish baseline distribution from the reference training dataset (data/train.csv, 5,634 rows). Compute Kolmogorov-Smirnov (KS) tests for numeric features (tenure, MonthlyCharges) and Population Stability Index (PSI) for categorical features (Contract, InternetService, PaymentMethod, and target Churn) against production batches (data/test.csv, 1,409 rows). Generate real-time interactive HTML dashboard (reports/churn_monitoring_report.html) and structured JSON alerts (reports/churn_monitoring_report.json).
